# Markdown 排版演示 —— 手把手教你写 Wiki

欢迎参与 KS2 Wiki 征稿!很多朋友说"我不会写代码,也没用过 Markdown,是不是就写不了文章?"

**完全不用担心。** Markdown 不是编程,它只是一套"用几个符号让文字变好看"的简单写法。你平时怎么打字,就怎么打字,只在需要**加粗**、列清单、放图片的时候,顺手加一两个符号就行。

这篇文章会把常用写法**从上到下演示一遍**:上半段是你看到的效果,配套的写法就藏在文章里。写文章时你可以打开本页右上角的"编辑",直接照抄下面的格式。

> 小提示:编辑页右侧有**实时预览**,你敲一句它就显示一句,不确定效果时看一眼预览即可,不用怕写错。

---

## 一、最最重要的一条:空一行才分段

这是新手唯一一个容易踩的坑,先讲清楚它,后面就一路顺畅了。

在 Markdown 里,**只按一次回车是不会分段的**。你以为分成了两行,渲染出来其实还是连在一起的一句话。想真正分段,要在两段之间**空一整行**(也就是按两次回车)。

写法对比:

```
这是第一句。
这是第二句。
```

上面这样写,显示出来会**挤成一行**。正确写法是中间空一行:

```
这是第一句。

这是第二句。
```

记住一句口诀就够了:**想换段落,就空一行。**

## 二、标题

标题用井号 `#` 开头,几个井号就是几级标题。井号后面要空一个空格。

```
# 一级标题(一般是文章大标题)
## 二级标题(章节)
### 三级标题(小节)
#### 四级标题(更细的分点)
```

本文里"一、二、三"这些就是二级标题 `##`,建议大家写文章时**多用二、三级标题分段**,读者能通过右侧目录快速跳转。

## 三、加粗、斜体、删除线

| 想要的效果 | 这样写 |
| --- | --- |
| **加粗强调** | `**加粗强调**` |
| *斜体* | `*斜体*` |
| ***又粗又斜*** | `***又粗又斜***` |
| ~~划掉的旧数据~~ | `~~划掉的旧数据~~` |

写攻略时,**技能名、关键数值**建议加粗,读者一眼就能抓到重点。

## 四、列表

### 无序列表(小圆点)

行首用 `-` 加一个空格:

```
- 凯瑞甘:近战英雄
- 泽拉图:刺客
- 阿塔尼斯:团队增益
```

效果:

- 凯瑞甘:近战英雄
- 泽拉图:刺客
- 阿塔尼斯:团队增益

### 有序列表(数字)

行首用 `1.` `2.` `3.`:

```
1. 先攒够资源
2. 升级主基地
3. 解锁二本兵种
```

效果:

1. 先攒够资源
2. 升级主基地
3. 解锁二本兵种

### 嵌套(子项缩进)

在子项前面**空两个或四个空格**,就能缩进成下一层:

```
- 前期
  - 优先经济
  - 保命技能点一级
- 中期
  - 转攻击装备
```

效果:

- 前期
  - 优先经济
  - 保命技能点一级
- 中期
  - 转攻击装备

## 五、表格

表格特别适合放数值、对比。用竖线 `|` 分隔每一列,第二行用 `---` 表示这是表头分隔线:

```
| 兵种 | 造价 | 人口 |
| --- | --- | --- |
| 陆战队员 | 50 | 1 |
| 掠夺者 | 100 | 2 |
| 攻城坦克 | 150 | 3 |
```

效果:

| 兵种 | 造价 | 人口 |
| --- | --- | --- |
| 陆战队员 | 50 | 1 |
| 掠夺者 | 100 | 2 |
| 攻城坦克 | 150 | 3 |

> 不用纠结竖线是否对齐,渲染时会自动对齐,你写得歪歪扭扭也没关系。

## 六、引用

行首加 `>`,用来引用原话、写提示、放注意事项:

```
> 注意:该数值基于最新版地图,旧版可能不同。
```

效果:

> 注意:该数值基于最新版地图,旧版可能不同。

## 七、链接和图片

### 链接

写法是**方括号放显示文字,圆括号放网址**:

```
更多内容见 [KS2 官方 Wiki 首页](/)。
```

效果:更多内容见 [KS2 官方 Wiki 首页](/)。

### 图片

和链接几乎一样,只是**前面多一个感叹号 `!`**。方括号里是图片说明(加载失败时显示):

```
![凯瑞甘立绘](图片网址)
```

图片网址可以是网上的图片链接,也可以先把图发给管理员上传后拿到链接。不确定怎么弄图片的话,先把文字写好,图片可以后补。

## 八、放视频(B站 / YouTube)

想在攻略里放讲解视频,**不用写复杂代码**,只要一行"短代码"就行。

### B站视频

单独一行写 `@bilibili(视频的 BV 号)`:

```
@bilibili(BV1xx411c7XD)
```

**BV 号在哪找?** 打开你要放的 B站视频,浏览器地址栏里 `bilibili.com/video/` 后面那串 `BV` 开头的就是,例如 `BV1xx411c7XD`。整串复制进括号即可。

效果就是一个可直接播放的视频框(自适应宽度、16:9):

@bilibili(BV1xx411c7XD)

### YouTube 视频

同理,单独一行写 `@youtube(视频ID)`:

```
@youtube(dQw4w9WgXcQ)
```

**视频 ID 在哪找?** YouTube 链接里 `watch?v=` 后面那一串,或短链 `youtu.be/` 后面那一串。

> **注意几点**
> - 短代码要**单独占一行**,上下最好各空一行。
> - 括号里**只填 BV 号 / 视频 ID**,不要把整条网址粘进去。
> - 目前只支持 **B站** 和 **YouTube**。直接粘一段 `<iframe>` 或其他网站的嵌入代码是**不会生效**的(出于安全考虑会被自动过滤)。

## 九、代码 / 特殊文本

如果你想让某段文字**原样显示、不被当成格式**(比如展示一段公式、命令、路径),用反引号 `` ` `` 包起来。

行内小段用一对反引号:

```
伤害公式是 `攻击力 × (1 - 护甲减免)`。
```

效果:伤害公式是 `攻击力 × (1 - 护甲减免)`。

整段用三个反引号包住(本文里那些灰底框就是这么来的):

    ```
    这里面的内容
    会原样显示,
    不会被格式化。
    ```

## 九、分隔线

单独一行写三个减号 `---`,就是一条横向分隔线,用来隔开大段落:

```
---
```

## 十、常见问题速查

| 我遇到的情况 | 原因 / 解决 |
| --- | --- |
| 两句话挤成一行了 | 中间**空一行**再写下一段 |
| `**`、`#` 这些符号显示出来了 | 符号后面/前面**要留一个空格**(如 `## 标题`、`- 列表`) |
| 加粗没生效 | 检查是不是用了中文的星号,要用英文半角 `*` |
| 表格没变成表格 | 第二行的 `| --- |` 分隔线不能少 |
| 不确定效果 | 看编辑页右侧的**实时预览** |

---

## 结语

其实你只要记住 **6 个符号**就能写出一篇漂亮的攻略:

- `#` 标题
- `**` 加粗
- `-` 列表
- `|` 表格
- `>` 引用
- **空行** 分段

剩下的写法用到时回来查这页就行。期待你的投稿,一起把 KS2 Wiki 建得更好!🎉
