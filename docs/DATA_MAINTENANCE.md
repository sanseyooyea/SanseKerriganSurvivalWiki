# 数据维护手册（非开发者）

本文面向**不写代码**的数据维护人员。你可以直接在网页上更新职业的**简介**和**攻略**，无需懂 Git 或编程。

> 如果你是开发者，要改属性数值 / 技能 / 兵种等结构化数据，请看 [../CONTRIBUTING.md](../CONTRIBUTING.md)。

## 你能改什么

登录后，进入任意职业详情页（`/classes/职业`），点 **「编辑」**，可以修改：

| 字段 | 说明 |
|---|---|
| **职业简介**（description） | 职业详情页顶部的介绍文字 |
| **攻略 / 玩法说明**（notes） | 支持 Markdown，写打法、连招、注意事项 |

保存后**即时生效**，无需等部署。每次修改都会记录是谁改的（updated_by）。

## 你不能在线改什么（为什么）

属性数值、技能列表、兵种 / 建筑数值**不能在线改**——这些数据和游戏地图绑定，由开发者从地图提取、经过自动校验后通过代码更新。原因：

- 数值一旦在线手滑改错，会绕过校验直接显示在站上，难追溯。
- 地图更新后开发者重新提取，会和你的在线修改冲突。

所以这类数据走「**代码 + 校验**」这条更严谨的路。

### 发现数值 / 技能错了怎么办

不要自己硬改，走反馈给开发者，二选一：

1. **站内「建议反馈」**（推荐）：在网站的反馈入口提交，写清楚哪个职业、哪个数值、正确值是多少、依据（如游戏内截图）。
2. **GitHub 提 issue**：https://github.com/sanseyooyea/SanseKerriganSurvivalWiki/issues

开发者核实后会改地图提取数据并上线。

## 攻略（notes）的 Markdown 速成

```markdown
## 小标题

普通段落文字。

- 列表项一
- 列表项二

**加粗**　*斜体*

> 引用 / 提示框

1. 有序步骤一
2. 有序步骤二
```

写完在编辑页能预览效果，确认无误再保存。

## 注意事项

- 内容会**公开展示**给所有访问者，注意措辞与准确性。
- 不要粘贴含脚本的 HTML（系统会自动过滤，但别依赖它）。
- 简介保持简洁；详细打法放攻略（notes）。
- 拿不准的数值类信息，走反馈让开发者核实，别写进攻略当事实。
